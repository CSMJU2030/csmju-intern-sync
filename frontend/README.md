# InternSync (Frontend Mockup)
ระบบบริหารและติดตามการฝึกงานสหกิจศึกษา - โมดูลเสริม CSMJU2030 MIS

## สถานะปัจจุบัน
พัฒนาหน้า UI จำลอง (Mockup) สำหรับงาน J2 เนื่องจากรอการ Integration กับ Core Hub (v1.7.0) 
- มีระบบจำลอง Login เลือกระดับสิทธิ์ (Student / Lecturer)
- หน้า Student: จำลองการยื่น Weekly Logbook
- หน้า Lecturer: จำลองระบบอนุมัติ Logbook และรอการต่อปลั๊กอินแผนที่ Leaflet สำหรับ GPS Check-in
