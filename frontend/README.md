# InternSync (Frontend)
ระบบบริหารและติดตามการฝึกงานสหกิจศึกษา - โมดูลเสริม CSMJU2030 MIS

## สถานะปัจจุบัน
หน้า UI บางส่วนยังเป็น mockup ระหว่างรอการ Integration กับ Core Hub (v1.7.0)
- มีระบบจำลอง Login เลือกระดับสิทธิ์ (Student / Lecturer)
- หน้า Student: จำลองการยื่น Weekly Logbook และขอพิกัดจากเบราว์เซอร์เมื่อกดส่ง
- หน้า Lecturer: แสดงแผนที่โลก Leaflet จากพิกัดที่นักศึกษาแนบมากับบันทึก

## ข้อมูลตำแหน่งบนแผนที่
เมื่อส่งบันทึก นักศึกษาจะได้รับคำขออนุญาตตำแหน่งจากเบราว์เซอร์ และพิกัดจะถูกส่งให้ OpenStreetMap Nominatim เพื่อระบุประเทศ หากไม่อนุญาตหรือระบุตำแหน่งไม่ได้ ยังส่งบันทึกได้โดยไม่มีพิกัด อาจารย์สามารถกรองหมุดตามประเทศได้ พิกัดจะแสดงบนแผนที่พร้อมชื่อนักศึกษา สัปดาห์ และเวลาส่ง

ตำแหน่งจะถูกเก็บไว้ใน localStorage ของเบราว์เซอร์เดียวกับข้อมูล logbook ในโหมด mockup เท่านั้น ยังไม่ได้ส่งไป backend หรือแชร์ข้ามอุปกรณ์ และอาจคลาดเคลื่อนตามความแม่นยำของอุปกรณ์ ไม่ใช่การยืนยันสถานที่ฝึกงาน การระบุประเทศใช้บริการ Nominatim ตามนโยบายการใช้งานของ OpenStreetMap
